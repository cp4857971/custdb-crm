# 通信客户资料库（fnOS Native 应用）

面向**通信行业营业/装维场景**的客户资料库：客户档案、套餐与费用、小业务、协议到期提醒。
按飞牛 fnOS [Native 应用案例](https://developer.fnnas.com/docs/examples/native/) 规范制作：
**Node.js 后端 + React 前端**，可打包为 `.fpk` 安装到飞牛 fnOS，界面按手机优先设计，适配安卓手机使用。

## 二、打包为 fnOS 应用（.fpk）

前置：NAS 需已安装 **Node.js v22 运行时**（应用中心安装 `nodejs_v22`）；本机安装飞牛官方打包工具 `fnpack`（下载地址 https://developer.fnnas.com/docs/cli/fnpack ，Linux：`chmod +x fnpack-1.2.3-linux-amd64 && sudo mv fnpack-1.2.3-linux-amd64 /usr/local/bin/fnpack`）。

```bash
npm install --workspaces
npm run build                 # 自动完成：构建前端 → 组装 backend+public → 安装依赖 → fnpack 打包
```

成功后在项目根目录生成 **`custdb.fpk`**。`fnpack` 未安装时脚本会在完成组装后提示手动执行：

```bash
fnpack build --directory custdb
```

> **打包要点（v0.0.4 修复）**：构建脚本会自动清理 `node_modules/.bin` 及所有指向构建机绝对路径的符号链接——此类链接会导致 NAS 安装时报“解压 app.tgz 失败”。若自行打包，请勿把构建机绝对路径符号链接打进 `app/server`。

### 安装到飞牛 fnOS

1. 飞牛系统 **应用中心 → 右上角设置 → 开发者模式（开启）**；
2. 应用中心 → **手动安装**，选择 `custdb.fpk`；
3. 安装后在桌面出现「通信客户资料库」卡片，打开即用（统一网关 `/app/custdb`，自动校验 NAS 登录态）。

### 数据存储与日志

- 数据：安装时系统创建 `data-share` 数据目录（`/var/apps/custdb/share/data`），后端通过 `TRIM_DATA_SHARE_PATHS` 读取；每位 NAS 用户一个独立数据空间。
- 日志：`${TRIM_PKGVAR}/app.log`（应用运行时变量目录）。
- 首次使用自动写入 10 条**虚构示例数据**，可在页面中删除或覆盖。

### 存储自定义：存储方式（JSON / SQLite）+ 数据路径

**存储方式（v0.0.10 起固定为 SQLite）**——数据统一存储在 SQLite 数据库 `custdb.db`（Node 内置 node:sqlite，零外部依赖，适合大数据量、并发写多）：

| 项目 | 说明 |
| --- | --- |
| 数据库 | `custdb.db`（数据目录下），正式客户与异网用户分表存储（customers / portin），按 NAS 用户隔离 |
| 数据路径 | 自定义（安装向导 / 设置页 / 环境变量 `DATA_DIR`），优先级：`config.json` 的 `dataDir` > 环境变量 > 默认 `data/` |
| 备份迁移 | 直接复制 `custdb.db` 即可；也可用「导出数据」生成 CSV / Excel / JSON 备份 |

**数据路径自定义（v0.0.5+，安装向导 v0.0.6）**——数据库存放目录可自定义：

- **安装时（v0.0.6）**：安装包自带向导，安装时可选填「自定义数据路径」，安装后自动写入 `config.json`，重启应用生效；
- **安装后**：在「设置」页填入**绝对路径**（如 `/var/apps/custdb/share/data/备份A` 或 `/vol1/存储空间1/custdb-data`）点「保存数据路径」，即写入 `config.json` 的 `dataDir` 字段，**重启应用后生效**；
- 也可手动编辑 `config.json` 的 `dataDir`，或设置环境变量 `DATA_DIR`；
- 优先级：`config.json` 的 `dataDir`（用户自定义）> 环境变量 `DATA_DIR`（部署默认）> 默认 `data/`；
- 路径必须是**绝对路径**且对应用户**可写**：应用文件区（`/var/apps/custdb/share/data`，即文件管理 → 应用文件 → custdb）内的子目录一定可写；存储卷/共享文件夹（`/vol1/...`）需先在文件管理中对该文件夹授予应用用户写权限，保存时会自动校验并提示。

> 修改 `dataDir` 后需**重启应用**生效；原有数据库文件不会自动搬移，如需保留请手动复制 `custdb.db` 到新目录（或先用「导出数据」备份再重新导入）。

## 二点五、管理员（v0.0.7+）

- **自动任命**：管理员名单（`config.json` 的 `admins` 字段）为空时，**第一个使用应用的用户自动成为管理员**；
- **管理入口**：管理员登录后，页面右上角出现「**管理**」按钮，含三个标签页：
  - **用户管理**：列出所有 NAS 用户及各自的客户总数 / 已到期 / 30天内 / 60天内 / 正常数量；每行「**添加客户**」可直接给该用户建档（新增加入该用户名下），「**查看**」进入该用户客户列表（管理员视角下可编辑、删除、导入）；下方为**管理员名单**（添加/移除管理员，移除后即失去管理权限）；
  - **套餐统计（v0.0.8）**：按套餐名称聚合——客户数、月费合计、平均月费、已到期数，可按「全部用户合计」或指定用户统计；
  - **协议统计（v0.0.8）**：**自动统计**卡片（总客户/已到期/30天内/60天内/正常/未设置）+ **未来 12 个月到期分布**条形图 + 已过期/未设置汇总，可切换统计范围；
- **权限边界**：非管理员调用管理接口一律返回 403；普通用户仍只能看到自己的数据（互不影响）；导入接口也支持管理员导入到指定用户（普通用户导入他人目标会被拒绝）。

## 二点六、异网用户（策反名单，v0.0.9）

- 页面顶部视图切换：**正式客户 | 异网用户**；
- 异网用户字段：**联系电话**（必填，一键拨打）、**家庭住址**、**套餐费用（元/月）**、**套餐名称**、**更换决策人**（家里决定是否换网的人）；
- 独立增删改查、关键词搜索（电话/住址/套餐/决策人）、统计卡（异网用户总数、月费合计、已标记决策人数）；
- 与正式客户**分开存储**（JSON：`<数据目录>/<用户>/portin.json`；SQLite：`portin` 表），互不干扰；
- 管理员视角下同样可跨用户查看/添加/编辑/删除异网用户，普通用户导入到他人仍被拒绝。

## 三、手机适配 / 安卓 APP（与服务端互通互联）

应用前端为移动优先设计，**电脑端与手机端访问同一台 NAS 上的同一份数据（单一数据源，双向读写）**，三种使用方式：

1. **手机浏览器直接使用（推荐）**：手机浏览器打开 `https://<NAS地址>/app/custdb`（或飞书/浏览器书签），
   在安卓浏览器菜单中选择「**添加到主屏幕**」，即获得接近原生 App 的体验（PWA 效果）。
2. **独立安卓 APK（v0.0.19）**：`mobile/CustDbApp` 是完整 Android Studio 工程（纯 WebView 壳 + 本地保存服务器地址，无第三方依赖）：
   ```bash
   cd mobile/CustDbApp
   # 用 Android Studio 打开本目录构建 app-debug.apk；或在已装 JDK17 + Android SDK + Gradle 的环境执行：
   gradle assembleDebug --no-daemon
   # 产物：app/build/outputs/apk/debug/app-debug.apk
   ```
   APK 安装后首次启动填写 NAS 地址（如 `http://192.168.1.100:5001/app/custdb` 或 `https://隧道域名/app/custdb`），
   内容直接加载 NAS 上的同一份数据；菜单可随时「修改服务器地址」。
3. **云打包**：也可用 HBuilder / 变色龙等云打包服务，将 `https://<NAS地址>/app/custdb` 包成 WebView APK。

> 互通互联要点：手机端（浏览器或 APK）通过**同一网关地址**访问后端 API，读写的是服务器上的同一份数据；
> 页面右上角「在线/离线」状态点可查看连接状态，「设置」可修改服务器地址并测试连接、查看存储方式与数据目录。

## 四、数据导入

页面右上角「导入数据」按钮，或直接调用接口：

**支持格式**（文件格式不限制，常见表格/文本均可）：
- **CSV**：逗号 / Tab / 全角逗号 / 分号 / 竖线分隔均可，支持引号包裹
- **Excel**：`.xlsx` / `.xls`
- **JSON**：数组，或 `{"customers": [...]}`
- **TXT**：任意分隔符文本

**表头自动识别**（中文/英文均可，列顺序不限）：

| 字段 | 可识别表头 |
| --- | --- |
| 姓名* | 姓名、客户姓名、客户、name |

**两种导入模式**：追加到现有数据 / 清空现有数据后导入（导入前请谨慎，清空不可恢复）。

## 五、Windows / Linux 桌面版（EXE，v0.0.23）

不装 NAS 也能用：**Windows 服务器 / Linux 服务器** 直接下载对应 zip，解压即运行（服务端自带前端界面目录，无需额外环境）。

| 包 | 内容 | 运行方式 |
| --- | --- | --- |
| `custdb-server-win-x64.zip` | Windows 服务端 EXE + web 界面目录 | 解压后双击 `custdb-server-win-x64.exe` → 浏览器访问 `http://本机IP:5001/app/custdb` |
| `custdb-server-linux-x64.zip` | Linux 服务端（免安装） | 解压后 `./custdb-server-linux-x64` |
| `custdb-client-win-x64.zip` | Windows 桌面客户端（启动器） | 双击 EXE 自动打开浏览器访问服务端；地址在旁置 `client-config.json` 修改 |
| `custdb-client-linux-x64.zip` | Linux 桌面客户端（启动器） | `./custdb-client-linux-x64` |

- 默认超级管理员 **admin / admin**（登录后请立即修改）；所有用户需登录验证
- 数据目录：服务端 EXE 同目录 `custdb-data/`（SQLite，可整体备份/迁移）
- 端口/路径环境变量：`PORT`（默认 5001）、`GATEWAY_PREFIX`（默认 /app/custdb）
- 客户端与服务端、Docker、fnOS 原生应用、安卓 APP **完全互通互联**（同一套数据与账号）

> **大文件分卷下载**（GitHub 网页单文件上限 25MB，故大包拆为分卷存放于仓库 `releases/`）：
> - `sp_server-win.z01` + `sp_server-win.zip` → 合并为 **custdb-server-win-x64.zip**
> - `sp_server-linux.z01` + `sp_server-linux.zip` → 合并为 **custdb-server-linux-x64.zip**
> - `sp_client-linux.z01` + `sp_client-linux.zip` → 合并为 **custdb-client-linux-x64.zip**
> 合并方法（三个包通用，把对应分卷放同一目录）：
> - **Windows**：用 7-Zip 打开 `sp_xxx.zip`（自动识别 .z01 分卷）直接解压；或 `copy /b sp_xxx.z01+sp_xxx.zip 目标.zip` 后解压
> - **Linux**：`zip -s 0 sp_server-win.zip --out custdb-server-win-x64.zip && unzip custdb-server-win-x64.zip`
> （分卷仅解决上传限制，内容与本地完整 zip 完全一致）

## 六、隐私提示

身份证住址、联系电话属于个人信息保护法中的**敏感个人信息**。本应用数据保存在你自有 NAS 的数据目录中，
请妥善保管 NAS 账号权限、勿将数据目录外传；示例数据均为虚构（脱敏），正式使用前请删除。
