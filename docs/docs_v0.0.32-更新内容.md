# CustDb v0.0.32 更新内容（2026-10-04）

> 通信客户资料库（CustDb）— 开发者/发布者：cp

## 本次更新：正式用户（管理员）可删除、编辑 正式客户与异网用户

**需求：**「正式用户 可删除，编辑 正式客户，异网用户」

### 一、改动内容

**前端门控调整（index-DIKYHF41.js，后端权限逻辑不变）**

1. 正式客户 / 异网用户卡片的**删除按钮**显示条件，由 v0.0.31 的「仅超级管理员（Ts()）」放宽为「**超级管理员 + 正式用户（管理员）**」：
   - 卡片组件（gm/xm）签名新增 `canDelete` prop，删除按钮按 `canDelete` 渲染；
   - 列表调用处传入 `canDelete = isSuper ‖ isAdmin`（isSuper/isAdmin 来自 `/api/admin/status`）；
   - **临时用户仍不显示删除按钮**（isAdmin=false）。
2. 编辑按钮维持原样（所有登录用户可见，后端按权限校验）；「连接与存储设置」入口维持仅超管显示（v0.0.31 保持）。

**后端权限（不变，已有逻辑）：**

| 操作 | 管理员（正式用户） | 临时用户 | 超管 |
| --- | --- | --- | --- |
| 编辑 | 仅自建（他人 403） | 可编辑绑定数据 | 任意 |
| 删除 | 仅自建（他人 403，进回收站） | 403 禁删 | 任意（可恢复回收站） |

### 二、端到端验证记录

| 场景 | 结果 |
| --- | --- |
| 管理员（uid 在名单）登录 `/api/admin/status` | isAdmin=true → 删除按钮显示 |
| 临时用户登录 status | isAdmin=false → 删除按钮不显示 |
| 管理员删除自建客户 | 200，进回收站（toRecycle:true） |
| 管理员删除他人（超管建）数据 | 403「仅可删除自己添加的数据…」 |
| 管理员编辑他人数据 | 403「仅可编辑自己添加的数据…」 |
| 临时用户删除客户 | 403「临时用户无删除权限」 |
| 超管删除任意数据 | 200，进回收站 |
| bundle 语法校验 / 源码起服务加载 / Linux 二进制冒烟 | 通过 |
| fpk 解包回读：version=0.0.32、checksum 匹配、bundle 含 canDelete 门控 | 通过 |

> 说明：UI 级浏览器验证受环境限制（浏览器沙箱与本地容器网络隔离），以上为接口 + 代码级验证；安装后请以实际界面为准。

### 四、更新方式

- **fnOS**：应用中心手动安装 `custdb.fpk`（覆盖升级，数据保留）。
- **Windows / Linux 服务端**：解压对应 zip 替换二进制与 `web/` 目录（保留 `custdb-data/` 数据目录）。
- **升级后**：正式用户（管理员）登录主页即可看到客户卡片的删除按钮（仅可删除自己添加的数据，他人数据点击返回 403 提示）；临时用户登录仍无删除按钮。
