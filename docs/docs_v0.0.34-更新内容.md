# 通信客户资料库 v0.0.34 更新内容（2026-10-04）

## 本轮需求

**打印视图为表格**（原打印预览为卡片式）。

## 实现说明

- 新增页面注入脚本 `public/assets/print-table.js`（由 `index.html` 引入，不动业务打包产物）。
- 点击「打印」（或直接 Ctrl+P）时，脚本监听 `beforeprint`，扫描**当前可见**客户列表，自动生成打印专用表格：
  - **正式客户**列：姓名 / 状态 / 剩余天数 / 套餐 / 联系电话 / 运营商 / 套餐费用 / 身份证住址 / 装机地址 / 小业务 / 备注 / 协议到期
  - **异网用户**列：联系电话 / 运营商 / 家庭住址 / 套餐名称 / 套餐费用 / 更换决策人 / 备注
- 打印结束（`afterprint`）表格自动移除，不影响页面正常显示。
- 搜索 / 筛选 / 页签切换后的当前列表即为打印内容；表格带边框、表头加粗，一页容纳更多客户，适合存档。
- 打印样式仅作用于 `@media print`，屏幕显示保持原卡片样式不变。

## 验证

- `node --check` 语法检查通过。
- DOM 单元测试：正式客户 2 张卡片 → 11 列表格、数据行正确（姓名/状态/剩余天数/套餐/联系电话/运营商/套餐费用/身份证住址/装机地址/小业务/协议到期）；异网用户 1 张卡片 → 6 列表格（联系电话/运营商/家庭住址/套餐名称/套餐费用/更换决策人）正确。
- 本地服务实测：`index.html` 正确引用 `print-table.js`（HTTP 200），页面加载正常。
- fpk 解包回读：`server/public/assets/print-table.js` 存在、`index.html` 含引用。
