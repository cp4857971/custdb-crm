# 通信客户资料库 v0.0.39 更新内容（2026-10-04）

## 本轮调整（主页客户列表视图优化 + 按协议到期排序）

### 一、主页客户列表视图优化（桌面 + 手机）

| 方向 | 实现 |
| --- | --- |
| **信息密度** | 桌面卡片列数随屏宽自适应：≥1200px **4 列**、≥900px 3 列、≥640px 2 列、手机单列；卡片内边距与字段行距收紧，**空字段行自动隐藏**（如「身份证住址 —」不再占行） |
| **布局与样式** | 卡片更紧凑（内边距 10px）、圆角 10px、浅阴影；hover 高亮边框（桌面）；字段标签等宽对齐 |
| **突出关键信息** | 姓名加大加粗；**剩余天数徽标化**（绿/橙/黄/红底色 + 边框按状态区分）；状态 chip 立体化；套餐名称加深；**电话行整行加底色高亮、点按区扩大**（含拨号圆点） |
| **操作便捷性** | 编辑/删除按钮等宽铺满卡片底部、按压缩放反馈；**手机端按钮加高至 44px**（触控标准）、字段字号加大 |

> 实现方式：注入式增强脚本 `assets/view-enhance.js`（增强 CSS + MutationObserver 卡片增强），**不动 React 打包产物**，打印视图（print-table.js）互不影响。

### 二、列表排序：按协议到期日期排前

- 正式客户列表（当前用户视图 + 管理员全库视图）改为 **按协议到期日期排序**：
  - **已到期**排最前 → **30 天内到期** → **60 天内到期** → 正常客户按到期日期**升序**（最早到期在前）；
  - **未设置到期日的客户排最后**；
  - 异网用户无协议到期字段，顺序不变。
- 实现：后端客户查询 SQL 增加 `ORDER BY contractEnd IS NULL, contractEnd ASC`（当前用户 / 管理员全库两处）。

### 三、验证

- 桌面浏览器实测（超管登录）：4 列布局 ✓；已到期客户排第一、未设置到期日客户排最后 ✓；空字段行隐藏、电话行高亮 ✓。
- 手机端（≤639px）：单列紧凑卡片 + 44px 操作按钮 + 字段字号加大（媒体查询规则验证通过）。

## 升级方式

- **fnOS**：应用中心 → 手动安装 custdb.fpk（覆盖升级，数据保留）；
- **Windows / Linux 服务端**：解压新 zip 替换旧目录（`custdb-data/` 保留不丢数据）；
- **安卓 APP / Electron 客户端**：无需更新（加载服务端页面，自动获得新视图）。
