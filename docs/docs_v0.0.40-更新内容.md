# 通信客户资料库 v0.0.40 更新内容（2026-10-04）

## 本轮调整（联系电话可直接复制，保留拨打电话）

- **电话行新增「复制」按钮**：正式客户 / 异网用户卡片电话行（高亮行）右侧增加「复制」按钮——点击一键复制完整联系电话到剪贴板；
- **复制成功提示**：按钮变绿色「已复制」，1.5 秒后自动恢复；
- **拨打保留**：电话号码本身仍为 `tel:` 可点击拨号链接，复制与拨打并存；
- **兼容性**：HTTPS / localhost 走 Clipboard API，局域网 http://IP 环境自动降级为隐藏 textarea + execCommand 复制；
- **手机端**：复制按钮加大触控（≥38px），便于手指操作。

> 实现方式：继续由注入式增强脚本 `assets/view-enhance.js` 完成（卡片电话行增强时自动追加复制按钮），不动 React 打包产物；与 v0.0.39 视图优化、打印表格互不影响。

## 验证

- 桌面浏览器实测：7 张客户卡片电话行均出现「复制」按钮 ✓；点击后按钮变「已复制」（绿色）✓；号码 `tel:` 拨打链接保留 ✓；1.5 秒自动恢复 ✓。
- 手机端（≤639px）：复制按钮触控尺寸加大（媒体查询规则验证通过）。

## 升级方式

- **fnOS**：应用中心 → 手动安装 custdb.fpk（覆盖升级，数据保留）；
- **Windows / Linux 服务端**：解压新 zip 替换旧目录（`custdb-data/` 保留不丢数据）；本轮服务端二进制无改动（仅前端增强），沿用 v0.0.39 二进制；
- **安卓 APP / Electron 客户端**：无需更新（加载服务端页面，自动获得复制按钮）。
