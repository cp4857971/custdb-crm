# 通信客户资料库 v0.0.38 更新内容（2026-10-04）

## 本轮需求

**删除套餐业务库（彻底移除，恢复手动输入）**

即：
1. 新增/编辑客户（正式客户、异网用户）时，**套餐名称、小业务不再弹出下拉选项**，恢复为纯手动输入框；
2. 管理后台**移除「套餐业务库」页签**（原五页签 → 四页签：用户管理 / 套餐统计 / 协议统计 / 系统设置）。

## 实现说明

| 位置 | 改动 |
| --- | --- |
| 前端 bundle（index-DIKYHF41.js） | ① 3 个 datalist 数据源置空（`cust-plan-list` 正式客户套餐、`portin-plan-list` 异网用户套餐、`cust-addon-list` 正式客户小业务）→ 输入框不再出现任何下拉选项；② placeholder 改为「请输入套餐名称」/「请输入小业务名称」；③ 管理模态框页签数组删除 `["library","套餐业务库"]` 项 |
| index.html | 移除 `picker-enhance.js` 引用（下拉箭头弹层增强不再加载） |
| 后端 server.js | **无改动**（`/api/plans`、`/api/addons` 等接口保留——前端初始化仍加载，避免报错；不影响业务功能） |

- 套餐名称 / 小业务现在完全手动输入，可填任意值（不再受业务库限制）。
- 手动输入保存链路实测正常（输入业务库没有的「定制套餐ABC」保存成功）。
- 套餐统计 / 协议统计等页签不受影响（统计基于客户数据，与业务库无关）。
