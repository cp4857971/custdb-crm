# v0.0.43 更新内容（2026-10-04）

## 本轮主题：蓝色收敛（蓝色区域整体太大、太抢眼 → 收敛）

根据需求「蓝色部分调整 → 蓝色区域整体太大、太抢眼，要收敛」，将**大面积深蓝渐变**收敛为**浅色底 + 深蓝点缀**：顶栏、统计卡改为浅色，蓝色只保留在文字、按钮、徽标、激活态等小面积位置，界面更轻盈、留白更足。

## 优化明细

### 1. 顶栏：深蓝渐变整条 → 白色底 + 浅蓝分割线
- **主页顶部栏**（HEADER.header）：取消整条深蓝渐变，改为**白色底** + 底部 1px 浅蓝分割线 + 轻投影；标题「通信客户资料库」改深蓝字、副标题浅灰蓝。
- **顶栏功能按钮**（检测中/导入/导出/打印/登录/+新增客户等）：白底 + 浅蓝描边 + 深蓝字，hover 浅蓝底，不再是一排白字压蓝底。
- **在线状态胶囊**：浅绿底绿字（状态色，不再叠深蓝底）。
- **控制台 / 导出中心顶栏**（.topbar）：同步收敛为白底 + 浅蓝分割线；用户身份胶囊浅蓝底深蓝字。

### 2. 统计数字卡：渐变大块 → 浅蓝底 + 深蓝数字（更矮）
- 主页「全部客户 / 已到期 / 30 天内 / 60 天内」四卡：取消深蓝渐变底，改为**浅蓝底（#EAF2FA）+ 细蓝边框**，卡片高度 102px → **78px**。
- 数字 **22px 深蓝加粗**（原白字压深蓝底），副标题浅灰蓝，激活卡浅蓝描边加深。

### 3. 页签 / 筛选激活：深蓝底白字 → 浅蓝底深蓝字
- 主页「正式客户 / 异网用户」页签：未激活深蓝字（白底），激活**浅蓝底深蓝字**。
- 筛选按钮（全部/已到期/…）：激活项**浅蓝底深蓝字**。
- 控制台页签（.tab.on）、导出中心激活项同步收敛。

### 4. 主按钮：渐变 → 纯品牌蓝（保留点缀）
- 「+新增客户」「登录」等主按钮保留品牌蓝 #17365D（去掉渐变），作为页面唯一大面积点缀色；其余蓝色全部收敛为浅色。

## 实现方式（重要）

- 仍为**注入式增强脚本 `assets/ui-enhance.js`（升级至 v0.0.43）**：在 v0.0.42 基础上追加「蓝色收敛」样式段，仅改视觉，**不修改任何业务逻辑**；三页面引用不变，自动加载新版。
- **后端无改动**，本轮仅前端增强；服务端二进制沿用 v0.0.42。
