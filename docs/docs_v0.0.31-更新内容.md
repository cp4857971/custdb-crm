# CustDb v0.0.31 更新内容（2026-10-04）

> 通信客户资料库（CustDb）— 开发者/发布者：cp

## 本次更新：删除按钮与「连接与存储设置」入口仅超级管理员显示

**需求：**
1. 「保留 正式客户 异网用户 删除 选项，除超级管理员，正式用户、临时用户不显示」
2. 「连接与存储设置 除超级管理员显示，正式用户、临时用户均不显示」

### 一、改动内容（前端打包产物 index-DIKYHF41.js，后端无改动）

1. **正式客户 / 异网用户卡片「删除」按钮仅超管显示**
   - 主页「正式客户」「异网用户」卡片操作列的删除按钮，包 `Ts()`（超管标志）条件：仅超级管理员登录时显示；正式用户（管理员）、临时用户均不显示。
   - 编辑按钮不受影响；卡片保留完整功能，后端删除权限逻辑不变（超管可删任意、管理员可删自建、临时用户 403 禁删）。
2. **主页「设置」入口（连接与存储设置弹窗）仅超管显示**
   - 桌面头部「设置」按钮与移动端菜单抽屉「设置」项均门控为仅超管显示；正式用户/临时用户看不到该入口，无法进入连接/数据路径/端口配置弹窗。

### 二、权限矩阵（v0.0.31，UI 显示层面）

| 角色 | 客户卡片「删除」按钮 | 主页「设置」（连接与存储设置）入口 |
| --- | --- | --- |
| 超级管理员 | ✓ 显示 | ✓ 显示 |
| 管理员（正式用户） | ✗ 不显示（后端删除自建权限保留） | ✗ 不显示 |
| 临时访问用户 | ✗ 不显示（后端本就 403 禁删） | ✗ 不显示 |

### 五、更新方式

- **fnOS**：应用中心手动安装 `custdb.fpk`（覆盖升级，数据保留）。

- **升级后**：以超级管理员（admin）登录可见全部卡片删除按钮与「设置」入口；正式用户/临时用户登录后不再显示删除按钮与「设置」入口。
