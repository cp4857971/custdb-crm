## 一、本轮更新亮点（v0.0.27）

**0. 本轮新增（v0.0.27，重点）：管理员 / 超级管理员主页全库视图**
- **管理员 / 超级管理员登录后，主页「正式客户 / 异网用户 / 统计」直接展示全库客户资料**——不分谁添加（含导入数据、其他管理员与普通用户的数据），无需进入控制台即可查看；
- **主页编辑 / 删除权限联动**：管理员在主页可编辑 / 删除**自己添加**的数据（自建数据，删除进回收站、超管可恢复），他人数据返回 403 明确提示；超级管理员可编辑 / 删除任意数据；
- **身份界定**：超级管理员、正式登录用户（管理员角色）→ 主页全库视图；操作员（operator）→ 仍只看到绑定数据；临时用户 → 脱敏 + 禁删不变。

**0. 本轮新增（客户端根治版）：独立窗口桌面客户端 + 单文件 EXE**
- **问题**：旧桌面客户端是“轻量连接壳”（读 `client-config.json` → 打开系统浏览器），本身无窗口；在未运行服务端的电脑上表现为“没有操作界面”。
- **根治**：全新 **Electron 独立窗口客户端**——双击直接弹出程序窗口（不依赖外部浏览器）；配置了服务器地址则内嵌加载服务端界面，连接失败自动进入**服务器设置页**（可改地址重连，也可“用系统浏览器打开”兜底）；支持菜单栏「服务器设置 / 刷新 / 退出」。
- **单文件 EXE**：Windows 版同时提供**单文件自解压 EXE**（`CustDbClient-v027-setup.exe`），双击解压即用，无需安装、免写注册表；解压时**保留**用户已保存的服务器地址（打包不覆盖 `client-config.json`）。
- **配置方式**：客户端同目录 `client-config.json`，内容为 `{"server":"http://服务器IP:5001/app/custdb"}`；程序启动时读取同目录配置文件。

**0. 本轮修复（v0.0.26，重点）**
- **修复：编辑客户/异网用户时，「协议到期日期」留空会误报“协议到期日期格式应为 YYYY-MM-DD”导致保存失败**。原因：PUT 校验把空字符串当非法日期。现已改为——选填字段为空即合法、正常保存；仅当填入非法格式（如 `2026/13/01`）时才拦截。
- **服务器错误详情回显**：接口未捕获异常（磁盘满、数据库只读/锁定等）不再返回空白错误页，改为 JSON 返回具体原因（如 `服务器错误：attempt to write a readonly database`），手机/网页端直接显示真实原因，便于定位部署问题。
- **全平台分发包重建**：服务端 Windows / Linux 二进制与 fnOS 应用包（custdb.fpk）均已重建；桌面客户端与安卓 APK 无需变更（薄壳，自动加载新版界面）。

**1. 管理员全库视图 + 打印 + 删除自建数据**
- 管理员登录后进入「管理控制台」，可查看**全部用户**的正式客户、异网用户与统计（新增 `/admin/all-customers`、`/admin/all-portin`、`/admin/all-facets`），列表展示每条数据的**归属用户**；
- 支持一键**打印**名单（打印样式内置，只留名单不显示操作按钮）；
- 管理员仅可删除**自己添加**的数据（`DELETE /admin/all-customers/:id`、`DELETE /admin/all-portin/:id`，非自建返回 403，超级管理员例外）；删除为**软删除**，数据进入回收站。

**2. 控制台角色自适应（super.html 重构）**
- 同一入口按登录角色自动切换：**管理员**（全库视图 + 自建数据删除按钮，他人数据只读灰字）；**超级管理员**（全库视图 + 回收站恢复/彻底删除 + 按创建人筛选）；
- 首页按角色显示「管理控制台 / 超级控制台 / 授权导出」入口。

**3. 全平台分发包重建（二进制以 Node 22 重新打包）**
- 服务端 Windows / Linux 单文件二进制重建（`custdb-server-win-x64.exe` / `custdb-server-linux-x64`），新增 **BASE_DIR 适配**，静态页从二进制旁 `web/` 目录读取（修复 pkg 打包后静态资源 404）；
- 桌面客户端启动器（win / linux）与安卓 APK 同步更新；
- 各形态与 fnOS / Docker / 安卓 APP **互通互联**（同一套界面、接口、账号与数据）。

## 五、安装 / 升级方式

- **fnOS**：应用中心 → 手动安装 → 选择 `custdb.fpk`；升级直接覆盖安装，数据保留（`/var/apps/custdb/share/data`）。
- **Windows / Linux 服务端**：解压对应 zip → 运行二进制 → 浏览器访问 `http://本机IP:5001/app/custdb`；数据在二进制旁 `custdb-data/`。
- **桌面客户端（推荐独立窗口版）**：解压 `custdb-client-win-x64-v027-window.zip`（或 Linux 版）→ 运行 `CustDbClient.exe` → 首次打开进入服务器设置页，填写服务端地址（如 `http://192.168.x.x:5001/app/custdb`）→ 连接；Windows 也可直接用 `CustDbClient-v027-setup.exe` 单文件自解压（双击解压到当前目录即用）。
- **安卓 APP**：解压 `CustDbApp-app-debug.apk.zip` 安装 APK，首次启动填写服务器地址。
- **Docker**：`backend/Dockerfile` + `docker-compose.yml`（源码部署）。

## 六、源码说明（GitHub 仓库 backend/）

- `backend/server.js`（约 78KB）：v0.0.27 服务端主程序（登录鉴权、客户/异网用户 CRUD、导入、三层权限、回收站、打印等），启动时自动加载 `server-ext.js`，**克隆后 `npm install && node server.js` 即可完整运行**；
- `backend/server-ext.js`：四段功能模块，由 `server.js` 自动 require（无需手动操作）——①套餐业务库 API（`/library/plans`、`/library/addons`、`/detect-operator`）②数据导出（`/export`，CSV/XLSX/JSON，临时用户授权码）③超级管理员全库（`/super/*`，回收站恢复/彻底删除）④管理员全库（`/admin/all-*`，删除自建数据）。内容与本地发布包内完整版（108,860 字节）逐字等价；
- 已验证：从 GitHub 拉取 `server.js` + `server-ext.js` 后启动，全部接口（含四段功能）端到端实测返回 200。

- Linux 二进制 zip 解包后端到端实测通过；Windows 二进制与客户端、APK 为同源构建产物。

## 八、注意事项

1. 默认超级管理员 **admin / admin**，登录后请立即修改密码；
2. 脱敏仅作用于**临时访问用户**视图，管理员/超管仍可见完整数据——临时账号请只分发给确需限时查看的人员；
3. 授权导出码**单次有效**、默认 30 分钟过期，用后即废；
4. 回收站数据不会被日常列表统计计入；彻底删除（purge）不可恢复；
5. 身份证住址、联系电话属敏感个人信息，请妥善保管数据目录与账号权限。
