# 通信客户资料库 · 安装配置说明（v0.0.23）

> 三种部署形态任选其一，功能完全一致：**fnOS 原生应用（.fpk）**、**Docker 容器**、**手机浏览器/PWA/安卓 APK**。
> 开发者/发布者：cp ｜ 版本：v0.0.23 ｜ 仓库：https://github.com/cp4857971/custdb

---

## 一、部署方式选择

| 方式 | 适用场景 | 数据存放 |
| --- | --- | --- |
| **fnOS 原生应用（.fpk）** | 飞牛 NAS（应用中心手动安装） | 应用数据目录（可自定义，安装向导填写） |
| **Docker 容器** | 飞牛 NAS Docker 应用中心 / 群晖 / 威联通 / 云服务器 / 软路由 | 数据卷挂载（`./custdb-data:/data`） |
| **手机浏览器 / PWA / 安卓 APK** | 手机端访问同一台 NAS/服务器的同一份数据 | 跟随服务端存储 |

## 二、fnOS 原生应用安装（.fpk）

### 1. 前置条件

- 飞牛 fnOS 系统版本 ≥ **1.1.3100**
- 应用中心安装 **Node.js v22 运行时**（应用包 `nodejs_v22`）——应用依赖

### 2. 打包（本机，可选——已有 fpk 可跳过）

```bash
fnpack build --directory custdb   # 生成 custdb.fpk（需先安装飞牛官方 fnpack）
```

### 3. 安装

1. 飞牛系统 → **应用中心 → 右上角设置 → 开发者模式（开启）**
2. 应用中心 → **手动安装** → 选择 `custdb.fpk`
3. 安装过程中出现「数据存储设置」向导：
   - **数据存储路径**：可留空（默认应用文件区 `/var/apps/custdb/share/data`）；或填自定义绝对路径（如 `/vol1/存储空间1/custdb-data`）
   - **服务端口**：可留空（默认 TCP 5001，局域网直连/隧道映射用）
4. 桌面出现「通信客户资料库」卡片，打开即用（统一网关 `/app/custdb`，自动校验 NAS 登录态、按用户隔离数据）

### 4. 数据与日志位置

| 项目 | 路径 |
| --- | --- |
| 数据库 | 数据目录下 `custdb.db`（SQLite） |
| 数据目录 | 安装向导自定义 / `config.json` 的 `dataDir` / 环境变量 `DATA_DIR` |
| 应用日志 | `${TRIM_PKGVAR}/app.log` |
| 应用配置 | `config.json`（`dataDir`、`port`、`admins` 等） |

## 三、Docker 部署

### 1. 目录结构

```
backend/
├── Dockerfile            # node:22-slim
├── .dockerignore
├── package.json / package-lock.json
├── server.js             # 服务端（全部业务逻辑）
└── public/               # 前端静态页面（已构建）
docker-compose.yml        # 一键编排
```

### 2. 方式 A：docker-compose（推荐）

```bash
docker compose up -d
# 访问 http://NAS-IP:5001/app/custdb
```

数据持久化：`./custdb-data:/data`（容器内数据目录），备份直接复制该目录。

### 3. 方式 B：命令行构建 + 启动

```bash
cd backend
docker build -t custdb:0.0.23 .
docker run -d --name custdb -p 5001:5001 -v $(pwd)/custdb-data:/data custdb:0.0.23
```

### 4. 常用环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | 5001 | TCP 服务端口（局域网直连 / 隧道映射） |
| `DATA_DIR` | `data/` | 数据存储目录 |
| `GATEWAY_PREFIX` | `/app/custdb` | 访问前缀（Docker 直连一般保持默认） |

## 四、手机端使用（互通互联）

1. **手机浏览器（推荐）**：打开 `https://<NAS地址>/app/custdb`（或局域网 `http://IP:5001/app/custdb`），安卓浏览器菜单「**添加到主屏幕**」→ PWA 桌面图标（全屏应用）
2. **安卓 APK**：安装 `app-debug.apk`（`mobile/CustDbApp` 构建），首次启动填写 NAS 地址（如 `http://192.168.1.100:5001/app/custdb` 或 `https://隧道域名/app/custdb`），数据即服务端同一份；菜单可随时「修改服务器地址」
3. 电脑与手机访问**同一台 NAS、同一份数据**（单一数据源，双向读写）

## 五、公网访问（隧道）

管理页「系统设置」内置四种隧道配置模板（统一映射 NAS 网关 **5666 端口** → `/app/custdb`）：

| 隧道 | 说明 |
| --- | --- |
| **frpc** | frp 内网穿透客户端 |
| **NPC (nps)** | nps 内网穿透客户端 |
| **cloudflared** | Cloudflare 隧道 |
| **节点小宝** | 易用型内网穿透 |

安全建议：① 修改默认密码；② 访客一律使用**临时访问用户**（限时账号，到期自动失效）；③ 只通过 HTTPS 域名访问。

## 六、登录与账号体系（所有用户需登录验证）

| 账号类型 | 说明 |
| --- | --- |
| **超级管理员 admin** | 默认密码 `admin`（**登录后建议立即修改**）；可删除任意管理员、管理套餐/小业务库、全库数据导出 |
| **正式登录用户** | 管理员创建/编辑/停用/删除，长期有效，绑定独立数据空间 |
| **临时访问用户** | 限时账号，到期自动失效并清理，只能查看绑定用户的数据 |

- **所有用户需登录验证（默认开启）**：未登录一律 401 并弹登录框；超管可在「系统设置 → ⓪ 严格登录验证」关闭
- 管理员：第一个使用应用的用户自动成为管理员；管理员可查看/管理所有用户的客户资料

## 七、套餐业务库与小业务库（v0.0.23）

- **套餐业务库（内置 33 条）**：移动（全家享融合/飞享/全球通/5G智享）、联通（沃家融合/冰激凌融合/沃派/冰激凌/5G冰激凌）、电信（**E家融合**/全家福融合/天翼畅享/5G畅享），类别=家庭融合/E家融合/单卡，含月费参考
- **小业务库（内置 21 条）**：各运营商云盘/云监控/路由器/视频彩铃等增值业务
- **自定义**：管理后台「套餐业务库」页，管理员可**添加/删除**自定义套餐与小业务（内置项标注「内置」不可删）
- **号码自动识别**：输入 11 位手机号自动填入运营商；**折扣**字段：正式客户与异网用户均可填（如 8折、95折）

## 八、数据导入导出

- **导入**：CSV / Excel(.xlsx/.xls) / JSON / TXT，中文/英文表头自动识别（姓名、联系电话必填），支持追加或清空后导入；支持表头：姓名、联系电话、身份证住址、装机地址、套餐名称、套餐费用、小业务、折扣、运营商、备注、协议起止日期
- **导出**：CSV / Excel / JSON；数据类型（正式客户/异网用户）、范围（当前用户/指定用户/全部用户【管理员】）；导出文件含到期状态与剩余天数；**管理员在线可直接导出并打印**（打印样式内置，只留名单）
- 备份迁移：直接复制 `custdb.db`，或用「导出数据」备份后再导入

## 九、常见问题

| 问题 | 处理 |
| --- | --- |
| 安装报“解压 app.tgz 失败” | 打包时清理了符号链接；请用官方脚本/fnpack 重新打包，勿手打含构建机绝对路径符号链接的包 |
| 忘记超管密码 | 编辑数据目录 `config.json` 重置 admins/初始密码，或重建数据目录 |
| 修改数据路径后数据不见了 | 修改 `dataDir` 需重启应用生效；旧库不会自动搬移，请先复制 `custdb.db` 或导出备份 |
| 公网打不开 | 检查隧道映射（5666 端口 → /app/custdb）、HTTPS 域名、登录验证是否拦截 |

## 十、隐私提示

身份证住址、联系电话属于《个人信息保护法》中的**敏感个人信息**。数据保存在自有 NAS 数据目录，请妥善保管 NAS 账号权限、勿将数据目录外传；示例数据均为虚构（脱敏），正式使用前请删除。
