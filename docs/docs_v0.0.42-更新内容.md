# v0.0.42 更新内容（2026-10-04）

## 本轮主题：全站视图再优化（v0.0.41 基础上继续深化）

在 v0.0.41 全站统一优化（顶栏渐变 / 表格紧凑 / 状态徽标 / 过期行高亮）基础上，v0.0.42 补齐**上一轮未覆盖的视觉盲区**：登录页、表单输入、弹窗、统计数字卡、滚动条、空状态、页面背景，四个方向继续全做。

## 优化明细

### 1. 整体风格（更深一层）
- **页面背景统一**：浅灰蓝底 + 左上/右上两处淡蓝径向光晕，页面不再素白。
- **登录页精致化**：登录卡 18px 大圆角 + 深阴影 + 白色描边；**标题栏改为深蓝渐变头**（渐变圆角顶），表单内边距/标签/登录按钮全宽渐变升级；手机端登录卡自动全宽。
- **滚动条美化**：全站细滚动条（9px、浅蓝圆角滑块、hover 加深）。
- **打印适配**：打印时隐藏页面背景，仅输出内容。

### 2. 信息密度（延续紧凑）
- 统计数字卡（主页「全部客户/已到期/30天内/60天内」）：**深蓝渐变底 + 白色大数字（26px 加粗）+ 副标题浅白**，关键数字一眼读取。
- 空状态（无数据提示）：居中「◌」图形占位 + 更柔和的灰字，不再是一行干瘪文字。

### 3. 关键信息突出（补充焦点与层次）
- **输入框/选择框/文本域统一焦点态**：聚焦时边框变品牌蓝 + 3px 浅蓝光环（focus ring），当前输入位置一目了然；placeholder 变浅灰。
- **卡片标题强化**：标题 14.5px 加粗、副标题 12px 浅灰；表格容器白色圆角包裹 + 细边框 + 轻阴影。
- **表头再强化**：th 加粗 700 + 深字色 + 底部 2px 分割线。
- **弹窗/模态框**：14px 大圆角 + 深阴影 + 渐变标题栏（深蓝渐变头），层次分明。

### 4. 操作便捷（延续触控）
- 顶栏用户身份胶囊化（半透明白底圆角胶囊，毛玻璃）。
- 顶栏操作按钮组间距统一；登录按钮全宽大按钮。
- Toast 提示：圆角 + 阴影 + 顶部滑入动画，反馈更醒目。

## 实现方式（重要）

- 仍为**注入式增强脚本 `assets/ui-enhance.js`（升级至 v0.0.42）**：在 v0.0.41 基础上追加样式段，仅改样式与视觉，**不修改任何业务逻辑**；三页面（super.html / export-center.html / index.html）引用不变，自动加载新版。
- **后端无改动**，本轮仅前端增强；服务端二进制沿用 v0.0.41。
