# v0.0.41 更新内容（2026-10-04）

## 本轮主题：全站视图统一优化

根据需求「视图优化 → 全部页面统一优化」，对**管理控制台 / 授权导出中心 / 主页**三处视图做整体升级，四个方向全做：**整体风格 · 信息密度 · 关键信息突出 · 操作便捷性**。

## 优化明细

### 1. 整体风格（视觉统一升级）
- **统一设计变量**：主色 `#17365D` → 深蓝渐变（135° 线性渐变），卡片圆角 12px + 细边框 + 柔和阴影，全局按钮 8px 圆角。
- **顶栏升级**：深蓝渐变背景 + 底部投影，顶栏按钮加毛玻璃效果。
- **主按钮升级**：渐变底 + 阴影，hover 上浮、按压缩放反馈；危险按钮描边红色。
- **页签升级**：圆角化，激活页签渐变底。
- **登录卡 / 提示条 / 授权码**：圆角与层次统一。

### 2. 信息密度（一屏更多数据）
- **表格紧凑**：表头/单元格内边距收紧（th 7px、td 6px，字号 12.5px），行高明显下降，7 行数据一屏尽览。
- **表头吸顶**：长列表滚动时表头固定（sticky），字段永不丢失。
- **斑马纹 + 行悬停高亮**：隔行浅底、悬停变蓝，视线快速定位。
- **移动端适配**：手机端表格字号 12px、内边距再收紧。

### 3. 关键信息突出（状态一眼可见）
- **状态徽标立体化**：胶囊圆角 + 描边 + 投影，到期色系统一（红=已到期 / 橙=30 天 / 黄=60 天 / 绿=正常）。
- **状态圆点**：到期状态徽标前置彩色圆点（红/橙/黄/绿），颜色即状态。
- **过期行整行高亮**：已到期行浅红底 + 左侧红条；30 天内到期行浅橙底 + 左侧橙条——逾期客户在表格中整行可见。
- **首列加粗**：姓名/首字段加粗加深蓝色，视觉锚点明确。
- **授权码芯片化**：导出中心授权码蓝底虚线框，等宽字体突出。

### 4. 操作便捷性（更好点、更好用）
- **按钮交互反馈**：所有按钮 hover 上浮 + 阴影、按压缩放，点击有明确反馈。
- **手机端触控**：按钮最小高度 36px，筛选条单行横向滚动（不换行挤压），顶栏收紧。

## 实现方式（重要）

- **注入式增强脚本 `assets/ui-enhance.js`**（新增，v0.0.41）：仅追加样式与 DOM 增强（MutationObserver 监听动态渲染的表格行，按状态徽标自动给整行加 expired/due30 状态类并回写 data-status），**不修改任何业务逻辑**，与主页 `view-enhance.js`（v0.0.39/40 卡片增强、电话复制）互不影响。
- 三个页面均引入：`super.html`（管理/超级控制台）、`export-center.html`（授权导出中心）、`index.html`（主页）。
- **后端无改动**，本轮仅前端增强；服务端二进制沿用 v0.0.40。
