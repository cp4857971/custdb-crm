# 通信客户资料库 v0.0.37 更新内容（2026-10-04）

## 本轮需求

**正式用户只有删除自建资料，可以查看全库资料**

即正式用户（管理员角色）：
1. **删除权限收紧为仅自建**：只能删除自己添加（createdBy=自己）的客户资料/异网用户资料，他人或导入的数据不可删除（403 提示）；
2. **全库查看保持**：仍可查看全库客户资料（不分谁添加、含导入数据），与 v0.0.27 全库视图一致。

## 实现说明

将 v0.0.33「正式用户可删除全库资料」回退为「仅可删除自建资料」，后端删除接口全部加自建校验（服务端强校验，前端点击他人数据时收到明确 403 提示）：

| 接口 | 修改前（v0.0.33） | 修改后（v0.0.37） |
| --- | --- | --- |
| `DELETE /api/customers/:id`（主页正式客户） | 管理员/超管可删任意 | 管理员仅可删自建（createdBy=自己），超管可删任意 |
| `DELETE /api/portin/:id`（主页异网用户） | 管理员/超管可删任意 | 同上 |
| `DELETE /admin/all-customers/:id`（管理控制台） | 管理员/超管可删任意 | 同上 |
| `DELETE /admin/all-portin/:id`（管理控制台） | 管理员/超管可删任意 | 同上 |

- 校验规则：`row.createdBy === 当前操作人` 才允许删除；**createdBy 为空的历史数据视为他人数据**（仅超管可删）；超管（isSuper）不受限制，可删除任意资料。
- 软删除与回收站保留：正式用户删除自建资料仍进入回收站（deleted_customers / deleted_portin 表，记录删除人与时间），超级管理员可在「超级控制台」恢复或彻底删除。
- 管理控制台（super.html）前端本就按 createdBy 控制删除按钮（自建显示「删除」、他人数据显示「他人数据」灰字、超管全显示），本轮补齐后端强校验双保险。
- 临时用户权限不变：禁删（403）、脱敏查看、凭授权码导出。

## 验证（本地实测）

构造测试库（正式用户 chenping + 超管 admin，各有数据）：
- chenping 删除**自己添加**的客户 → `{"deleted":...,"toRecycle":true}` 成功，数据进入回收站（超管可在回收站看到并恢复）✓
- chenping 删除**他人（超管）添加**的客户 → HTTP 403 `{"error":"仅可删除自己添加的资料"}` ✓
- chenping 查看全库 → 可见超管添加的数据（全库视图保持）✓
- 管理员/超管登录、临时用户权限均回归正常 ✓
