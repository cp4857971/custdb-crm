# CustDb v0.0.33 更新内容

> 发布日期：2026-10-04 ｜ 开发者/发布者：cp ｜ 仓库：https://github.com/cp4857971/custdb-crm

## 本轮需求

> 「正式用户 可删除 编辑 全库资料，正式用户可以创建临时用户，生成授权码」

- **正式用户（管理员）可删除、编辑全库资料**：不再限于「自己添加的数据」——正式客户与异网用户（不分谁添加、含导入数据、含其他管理员/用户添加的数据），管理员均可编辑与删除。
- **创建临时用户 + 生成授权码**：v0.0.30 已具备（管理员在「系统设置 → ③ 临时访问用户」创建临时用户、「导出中心」生成随机授权码），本轮属重申，保持不变。

## 改动明细

### 后端（server.js / server-ext.js，共六处放开）

| 接口 | 改动 | 说明 |
| --- | --- | --- |
| `PUT /customers/:id` | 移除「仅可编辑自己添加」403 分支 | 管理员/超管可编辑全库正式客户 |
| `PUT /portin/:id` | 移除「仅可编辑自己添加」403 分支 | 管理员/超管可编辑全库异网用户 |
| `DELETE /customers/:id` | 移除「仅可删除自己添加」403 分支 | 管理员/超管可删除全库正式客户，删除进回收站 |
| `DELETE /portin/:id` | 移除「仅可删除自己添加」403 分支 | 管理员/超管可删除全库异网用户，删除进回收站 |
| `DELETE /admin/all-customers/:id` | 移除「仅可删除自己添加」403 分支 | 管理控制台全库删除同步放开 |
| `DELETE /admin/all-portin/:id` | 移除「仅可删除自己添加」403 分支 | 管理控制台全库删除同步放开 |

- 代码中以注释标注 `// v0.0.33：管理员可编辑全库资料（不再限自建）` / `// v0.0.33：管理员/超管可删除全库资料（不再限自建）；删除进回收站，超管可恢复`。
- **临时用户始终无删除权限**：`isTempUser` 分支保留，DELETE 返回 403「临时用户无删除权限」。

### 前端

- **无改动**：删除按钮显示条件沿用 v0.0.32（超级管理员 + 正式用户/管理员显示，临时用户不显示）；编辑按钮本就管理员可见。

## 升级说明

- **fnOS**：应用中心手动安装 `custdb.fpk` 覆盖升级即可，数据保留；历史示例数据启动自动清理。
- **Windows / Linux 服务端**：解压 zip 覆盖替换二进制（`web/` 目录与 `custdb-data/` 数据目录保留）。
- **安卓 / 桌面客户端**：无需更新（薄壳自动加载服务端新界面）。
- 默认超管 **admin / admin**，登录后请立即修改密码。
