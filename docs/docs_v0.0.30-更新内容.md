# CustDb v0.0.30 更新内容（2026-10-04）

> 通信客户资料库（CustDb）— 开发者/发布者：cp

## 本次更新：正式用户（管理员）可创建临时用户并生成授权码

**需求：**「正式用户 可以创建临时用户，并生成授权码」

### 一、改动内容

1. **后端权限放宽（server.js，temp-users 三接口）**
   - `GET /admin/temp-users`：原「仅超级管理员」→ **管理员**可用；管理员只返回**自己创建**的临时用户，超管返回全部。
   - `POST /admin/temp-users`：原「仅超级管理员」→ **管理员**可创建，每条临时用户自动记录创建人 `createdBy`（登录账号）。
   - `DELETE /admin/temp-users/:username`：原「仅超级管理员」→ **管理员**可删除，但仅限**自己创建**的临时用户（他人创建返回 403「仅可删除自己创建的临时用户」），超管可删除任意。
   - 授权码接口（POST/GET/DELETE `/admin/export-codes`）本就需要管理员权限，无需改动：管理员登录后即可在「导出中心」生成临时用户导出所需的随机授权码。

2. **前端门控放开（bundle 两处条件替换）**
   - 「系统设置」页签：超管专属 → **超管 + 管理员**可见。
   - 「③ 临时访问用户」区块：超管专属 → **超管 + 管理员**可见（管理员进入后只见自己创建的临时用户；「① 超级管理员」「② 正式登录用户」中的超管专属部分不变，管理员仍看不到改密码/严格登录等超管功能）。

### 二、权限矩阵（v0.0.30）

| 角色 | 创建临时用户 | 查看临时用户 | 删除临时用户 | 生成导出授权码 |
| --- | --- | --- | --- | --- |
| 超级管理员 | ✓ | 全部 | 任意 | ✓ |
| 管理员（正式用户） | ✓（v0.0.30 新增） | 仅自己创建的（v0.0.30 新增） | 仅自己创建的（他人 403） | ✓ |
| 操作员 | ✗（403） | ✗ | ✗ | ✗ |
| 临时访问用户 | ✗ | ✗ | ✗ | ✗ |

### 五、更新方式

- **fnOS**：应用中心手动安装 `custdb.fpk`（覆盖升级，数据保留）。
- **Windows / Linux 服务端**：解压对应 zip 替换二进制（保留 `custdb-data/` 数据目录与 `web/`）。
- **升级后**：管理员登录 → 右上角「系统设置」→「③ 临时访问用户」创建临时账号；「导出中心」生成授权码后把账号与授权码发给临时用户，临时用户登录后凭码导出。
